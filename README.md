# family · 가족금고

GitHub Pages에서 화면을 제공하고 Google Drive `family` 전용 폴더에 원본을 저장하는 가족금고입니다. ChatGPT 로그인과 부모님의 Google 계정은 사용하지 않습니다.

## 현재 상태

- **이전 준비 중이며 아직 사용 가능한 새 금고가 아닙니다.** Google Apps Script 생성·계정 승인·실제 배포 및 브라우저 검증이 남아 있습니다.
- `config.js`의 `apiUrl`은 실제 배포가 검증될 때까지 비워 둡니다. 연결 전에는 저장 완료를 표시하지 않습니다.
- 기존 사이트와 기존 데이터는 삭제하거나 변경하지 않았습니다. 기존 정보 1건의 이전은 별도로 검증해야 합니다.
- 서버와 브라우저 암호화 동작의 모의 환경 테스트 13개를 통과했습니다. 이 결과는 실제 Google 배포/CORS/휴대폰 동작 검증을 대신하지 않습니다.

## 구성

- `index.html`, `app.js`, `transport.js`: 사람별 보관함, 통합 검색, 가족 비밀번호 및 기기 기억, 사진 첨부.
- `apps-script/Code.gs`: Google Drive 저장 서버. 특정 `family` 폴더만 코드에서 사용합니다.
- `apps-script/appsscript.json`: 소유자 권한 실행, 비로그인 방문 허용.
- Google Drive `family/family-vault.json`: 정보, 가족·기기 설정, 사진 참조의 원본.
- `family/photos/`: AES-GCM으로 암호화한 사진 파일.
- `family/backups/`: 변경 전 원본 사본. 기존 사본과 사진을 자동 영구 삭제하지 않습니다.
- `family/family-recovery-key.json`: 소유자 비공개 복구 키. 공개하거나 GitHub에 커밋하지 않습니다.

## 배포 순서

1. `momothebestdog@gmail.com`으로 Apps Script 프로젝트 `family`를 생성합니다. 연결된 Google Drive 폴더는 코드의 고정 ID를 사용합니다. 프로젝트 파일도 해당 전용 폴더로 정리합니다.
2. `Code.gs`와 매니페스트를 반영합니다. DriveApp 사용 때문에 Google의 Drive 접근 승인이 필요합니다. 코드가 사용하는 경로는 family로 제한하지만 OAuth 범위 자체는 Drive 전체이므로 승인 화면에서 확인해야 합니다.
3. 편집기에서 `provisionFamily`를 한 번 실행합니다. 재실행해도 기존 금고와 키를 초기화하지 않습니다. 초기 설정 링크는 실행 로그에만 나타나며 GitHub에 저장하지 않습니다.
4. 웹 앱으로 배포합니다. 실행 사용자: 소유자. 접근 사용자: 모든 사용자(비로그인 포함). 이 공개 입구는 인증된 금고 데이터 공개와 다릅니다. 데이터 요청은 기기 토큰과 가족별 권한 확인이 필요합니다.
5. 실제 `/exec` 주소를 `config.js`에 연결합니다. GET 서비스 확인, 비로그인 데이터 차단, GitHub Pages 출처의 POST/CORS, 실제 사진 업로드·재열람을 검증합니다.
6. 최초 설정 링크로 관리자가 비밀번호를 직접 정하고 가족별 비밀번호를 부여합니다. 기존 금고 기록을 옮긴 뒤 내용과 사진을 대조합니다.
7. 일반 접속 주소에서 부모님 기기로 최초 등록과 재접속을 확인합니다. 검증 전에는 기존 사이트를 종료하거나 기록을 삭제하지 않습니다.

## 보존과 복구

브라우저 저장소에는 기기 접속 토큰만 보관합니다. 앱을 지우거나 브라우저 데이터를 지워도 원본은 Google Drive에 남으며 재접속 시 비밀번호를 다시 입력합니다. 소유자가 Google 계정과 저장공간을 유지해야 합니다.

원본을 변경하기 전에 이전 파일을 backups에 복사합니다. 저장 실패 시 화면에 성공으로 표시하지 않습니다. 휴지통 복구와 사진 숨김은 지원하며, 사진을 숨겨도 원본 파일을 삭제하지 않습니다. 정보·사진 전체 사본을 관리자 화면에서 JSON으로 내려받을 수 있습니다. 이 사본은 읽을 수 있는 평문이므로 개인 공간에 보관해야 합니다.

오래된 상태 복구 시에는 쓰기를 중단하고 현재 원본을 별도 복사한 뒤, 원하는 backups 파일을 `family-vault.json`의 내용으로 복원합니다. 복원본에는 이전 기기 상태도 포함되므로 기기 목록을 점검합니다. 암호화 복구에는 `family-recovery-key.json`도 필요합니다. 복구 키와 데이터 파일을 함께 잃으면 내용을 되살릴 수 없습니다.

## 인증과 암호화의 범위

가족 비밀번호는 브라우저 PBKDF2-SHA256 210,000회로 검증값을 만들고 서버에서 비공개 pepper를 사용한 HMAC으로 저장합니다. 기기 토큰은 원문 대신 HMAC만 Drive에 저장합니다. 8회 오입력 시 해당 계정의 로그인을 15분 제한합니다. 이는 가족용 초기 구현이며 독립된 보안 감사를 거치지 않았습니다.

정보 제목·관련 정보·메모·보관 내용과 사진은 브라우저 AES-GCM으로 암호화합니다. 보관함 이름·가족 이름·분류·공유 대상·사진 파일명·기기 이름은 일반 정보로 비공개 Drive에 저장합니다. 서버가 인증된 가족에게 복호화 키를 전달하므로 종단간 암호화가 아닙니다. 가족별 접근은 서버가 공유 대상을 확인해 제한합니다. 공개 GitHub에는 코드만 두며 실제 정보·사진·복구 키·비밀번호·접속 토큰은 넣지 않습니다.
